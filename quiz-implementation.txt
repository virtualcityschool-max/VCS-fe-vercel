  ---
  Student — Submit Quiz
  POST /api/v1/quizzes/1/submit/

  Timing guards:
  - now < published_at → 400 Not available yet
  - now > due_date → 400 Window closed
  - Already submitted → 400 Already submitted
  - Not enrolled → 403

  Payload:
  {
    "answers": [
      { "question_id": 1, "selected_options": [1]    },
      { "question_id": 2, "selected_options": [5, 6] },
      { "question_id": 3, "text_answer": "OOP is a paradigm where code is structured using objects and classes." }
    ]
  }

  Answer rules per type:

  ┌─────────────────┬──────────────────────┬─────────────┐
  │      Type       │   selected_options   │ text_answer │
  ├─────────────────┼──────────────────────┼─────────────┤
  │ SINGLE_CHOICE   │ exactly 1 option ID  │ omit        │
  ├─────────────────┼──────────────────────┼─────────────┤
  │ MULTIPLE_CHOICE │ 1 or more option IDs │ omit        │
  ├─────────────────┼──────────────────────┼─────────────┤
  │ TEXT_FORMAT     │ omit or []           │ required    │
  └─────────────────┴──────────────────────┴─────────────┘

  Response 201 — MCQ graded immediately, text marked pending:

  ┌─────────────────┬─────────────────────────────────────────┐
  │ Student selects │                 Result                  │
  ├─────────────────┼─────────────────────────────────────────┤
  │ [5]             │ :white_check_mark: Full 5 marks                         │
  ├─────────────────┼─────────────────────────────────────────┤
  │ [5, 6]          │ :white_check_mark: Full 5 marks                         │
  ├─────────────────┼─────────────────────────────────────────┤
  │ [5, 7]          │ :white_check_mark: Full 5 marks — one correct is enough │
  ├─────────────────┼─────────────────────────────────────────┤
  │ [7]             │ :x: 0 marks                              │
